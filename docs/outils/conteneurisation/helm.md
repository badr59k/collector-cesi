# Helm

**À quoi ça sert ?** c'est un gestionnaire de packages pour Kubernetes qui permet d'installer et de configurer des applications à partir de modèles appelés Charts.

**Dans Collector :** on utilise Helm pour installer et configurer des outils d'infrastructure comme Coroot et son Operator. Les fichiers values.yaml permettent de personnaliser les installations, notamment les ressources, le stockage et les images Docker utilisées.
