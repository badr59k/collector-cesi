# K8s

**À quoi ça sert ?** permet de déployer et gérer automatiquement des applications conteneurisées (redémarrage en cas de panne, gestion des Pods, répartition du trafic, etc.).

**Dans Collector :** fait tourner notre backend Spring Boot et PostgreSQL, avec deux Pods pour le backend, des contrôles de santé et un stockage persistant pour la base de données.
