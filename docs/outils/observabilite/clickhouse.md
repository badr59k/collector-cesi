# ClickHouse

**À quoi ça sert ?** c'est une base de données orientée colonnes, optimisée pour stocker et analyser rapidement de grandes quantités de données.

**Dans Collector :** on utilise ClickHouse avec Coroot pour stocker les logs, les traces et les profils de performance de notre infrastructure. Cela permet à Coroot d'analyser les événements et de faciliter le diagnostic des problèmes rencontrés par nos microservices.
